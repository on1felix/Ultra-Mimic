----------

- документация: README.md, README.en.md, LICENSE, proof.png

Что НЕ включено (восстанавливается командами)
---------------------------------------------
- node_modules\        npm install
- dist\               npm run build
- src-tauri\target\   cargo / tauri build
- src-tauri\gen\      генерируется автоматически
- mimic.png, public\mimic.png  (не используются)

Как собрать
-----------
Из корня папки (двойной клик или из консоли):

    build.bat

Скрипт сам подставит Rust-тулчейн и окружение MSVC, соберёт фронтенд и Rust,
положит готовый exe и напечатает размер с SHA256.

Готовый файл: src-tauri\target\release\Ultra Mimic.exe

Режим разработки:

    dev.bat
